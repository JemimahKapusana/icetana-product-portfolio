# icetana Product Portfolio

An independent single-page product-management case study. The website invites readers into a **fictional icetana leadership meeting**, then walks through real public research into mining applications for computer vision. No company affiliation or internal information is implied.

## Version 3: what changed

- Preserved the original pink/plum theme, fonts, animated hero, mobile navigation and eight lifecycle cards.
- Completed the **Idea & Opportunity** chapter with a clearly identified simulated meeting decision.
- Expanded **Discovery & Research** with a chronological story: mining vehicle collisions considered then parked, foreign-object conveyor monitoring identified, BHP headline figures, video, international and Australian case studies, competition, target-customer hypothesis and research recommendation.
- Primary-source links appear beside relevant claims, with reporting/estimate limitations noted.
- BHP's case covers both oversized material and foreign objects; the proposed portfolio concept focuses on **foreign objects only**.
- Further customer discovery is recommended. Later product phases remain a hypothetical exercise unless evidence supports development.

## Update the live GitHub Pages site

1. Unzip this archive and open the `icetana-product-portfolio-v3` folder.
2. Go to your `JemimahKapusana/icetana-product-portfolio` repository on GitHub.
3. Choose **Add file → Upload files**.
4. Select the five files *inside* the folder: `index.html`, `styles.css`, `script.js`, `README.md`, `.nojekyll`. Do not upload the ZIP or enclosing folder.
5. Commit the changes to `main`. If GitHub asks, choose to replace files with matching names.
6. GitHub Pages should redeploy from `main` automatically. View https://jemimahkapusana.github.io/icetana-product-portfolio/ and use Ctrl+F5 or a private browsing tab if an old version is cached.

No framework or build step is required. The YouTube embed uses privacy-enhanced mode; a direct video link is included in case the embed is blocked.

## Files

- `index.html` contains the content and source links.
- `styles.css` handles visual design, responsiveness and motion.
- `script.js` handles mobile navigation, scroll position and tilt.
- `.nojekyll` enables a straightforward static GitHub Pages deployment.

## Research boundaries

Figures are attributed to public case studies and reporting and should not be presented as independently verified commercial outcomes. WorkSafe evidence documents vehicle safety incidents but does not validate a product market. Anglo American's Dawson Mine example deals with **belt clip failures**, a related but different vision application. No real mining-company customer interviews or icetana approvals are claimed.
