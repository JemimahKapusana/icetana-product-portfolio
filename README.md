# icetana Product Portfolio

A single-page portfolio showing how I would explore a possible new market for video analytics, using a **fictional leadership scenario** involving icetana AI.

This is an independent, hypothetical case study. It is **not affiliated with, commissioned by, or endorsed by icetana AI**. Public research will be sourced; any simulated meetings or results will be labelled as simulated.

## The website

- Clear navigation with all eight lifecycle phases listed on desktop.
- A **Navigation menu** button on phones and tablets.
- An animated, 3D-style opportunity visual in the introduction.
- Eight clickable lifecycle cards with gentle mouse tilt.
- Readable layouts for phones, tablets and computers.
- Reduced-motion support for visitors who prefer less animation.
- Links to public research sources in the first chapter.

## Publish or update it on GitHub Pages

1. Unzip the website folder on your computer.
2. Open your `icetana-product-portfolio` GitHub repository.
3. Select **Add file → Upload files**.
4. Upload `index.html`, `styles.css`, `script.js`, `README.md` and `.nojekyll` **into the root of the repository**. If there are existing files with the same names, the new versions replace them.
5. Select **Commit changes**.
6. If GitHub Pages is not already enabled, go to **Settings → Pages**, choose **Deploy from a branch**, then **main**, **/(root)**, and **Save**.
7. Open the link shown under **Settings → Pages**. If the previous design is cached, refresh the page (Ctrl + F5 on Windows).

## Update content later

- `index.html` contains all the website text and content.
- `styles.css` controls design and animation.
- `script.js` powers the mobile menu, section highlighting and interactive 3D tilt.

No extra software or external JavaScript libraries are required. The fonts use Google Fonts when available.
