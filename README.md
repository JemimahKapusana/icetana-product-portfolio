# STEM Baddie Studio · Mining Market Opportunities

An interactive, single-page product management portfolio exploring a hypothetical business question: **Could icetana AI expand into the mining industry?**

This is an independent learning and portfolio case study. It is **not affiliated with, commissioned by, or endorsed by icetana AI**. Simulated company discussions and business outcomes will be labelled separately from real research and genuine technical experiments.

## What is included?

- Eight clickable product lifecycle phases
- Sticky desktop navigation and mobile section menu
- Optional interactive 3D card tilt
- Responsive layouts and keyboard navigation
- Clear initial Phase 1 content, with later phases awaiting evidence

## Publish using GitHub Pages

Go to **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then **Save**.

## Update the website

- `index.html`: text and page sections
- `styles.css`: colours, layout and styles
- `script.js`: mobile menu, active navigation and card tilt

No build tools or external JavaScript libraries are required. Web fonts are loaded through Google Fonts when internet access is available.
